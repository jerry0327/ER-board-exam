# Archive

這裡保存急專補給站的歷史參考、recovery notes、舊版視覺與已淘汰但仍可能有診斷價值的檔案。

## Archive is not production

`archive/` 內的檔案不應被 runtime 默認載入。若某個舊檔重新成為正式功能的一部分，應經過 review 後移到正確的 canonical 位置。

## Recovery rule

只標示已確認的資訊。來源不明、版本不明、無法驗證是否曾上線的實驗檔，不會因為「看起來很像」就被標成正式舊版。

歷史 UI 截圖放在 `docs/screenshots/legacy/`，便於日後最新版匯入時做人工視覺比對。
